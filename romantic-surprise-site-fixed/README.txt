ROMANTIC SURPRISE WEBSITE — HOW TO OPEN

IMPORTANT:
Do not download or open index.html/surprise.html by themselves.
The HTML files need the styles.css, script.js, and assets folder beside them.

1. Extract the entire ZIP file.
2. Open the extracted folder named romantic-surprise-site-fixed.
3. Double-click index.html.

HOW TO ADD YOUR OWN PHOTOS

1. Open the assets folder.
2. Copy four photos into it.
3. Rename them exactly:
   photo-1.jpg
   photo-2.jpg
   photo-3.jpg
   photo-4.jpg
4. In surprise.html, replace these four paths:
   assets/photo-1.svg -> assets/photo-1.jpg
   assets/photo-2.svg -> assets/photo-2.jpg
   assets/photo-3.svg -> assets/photo-3.jpg
   assets/photo-4.svg -> assets/photo-4.jpg

Keep every file in the same folder structure. Moving only the HTML file will break images and styling.
